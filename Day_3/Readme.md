# RAG Workshop — День 3

Практичний воркшоп про роботу з локальними LLM (Ollama), їх порівняння з хмарними моделями (OpenAI) та оцінювання якості відповідей (evaluation).

## Що розглянемо

1. **Локальні LLM: що це і коли варто.** Локальна LLM працює на вашому залізі, без зовнішнього API.
2. **Ollama та альтернативи.** Основний інструмент воркшопу — Ollama. Коротко розглянемо й альтернативи: Hugging Face, Docker Model Runner та vLLM.
3. **Як вибрати модель: бенчмарк exact-match.** Порівняємо Ollama та OpenAI на задачах з однозначною правильною відповіддю (MMLU).
4. **LLM-as-a-Judge.** Порівняємо відповіді моделей на відкритих питаннях за допомогою окремої LLM-судді.
5. **Готові фреймворки для оцінювання** (RAGAS, DeepEval, TruLens, OpenAI Evals).
6. **Готові дашборди і leaderboard-и** (LLM Stats, Vellum).

## Підготовка до заняття

### 1. Скачайте і розгорніть архів з матеріалами з репозиторію
Завантажте архів з матеріалами воркшопу та розпакуйте його в зручну для вас папку на комп'ютері.

### 2. Відкрийте папку Day 3 в VS Code
`File → Open Folder...` → виберіть розпаковану папку `Day 3`.

### 3. Створіть файл `.env`
У корені папки `Day 3` створіть файл `.env` з наступним ключем:

```
OPENAI_API_KEY=Ваш_ключ_OpenAI_API_тут
```

Ключ потрібен для порівняння та оцінки відповідей моделей (розділ "2. Порівняння та вибір моделей" в ноутбуці).

> Не комітьте `.env` у git та не діліться ключем публічно.

### 4. Створіть і активуйте віртуальне середовище Python
Як описано в розділі **"000 — Підготовка: робота з віртуальним середовищем (venv)"** ноутбука `LLM_selection_comparision.ipynb`:

**Створення:**
```bash
python3 -m venv .venv
```

**Активація**

macOS / Linux:
```bash
source .venv/bin/activate
```

Windows (PowerShell):
```powershell
.venv\Scripts\Activate.ps1
```

Windows (cmd):
```cmd
.venv\Scripts\activate.bat
```

**Перевірка, що середовище активовано:**
```bash
which python
```

**Вихід із середовища:**
```bash
deactivate
```

### 5. Встановіть розширення для Python і Jupyter (за потреби)
Якщо ще не встановлені — додайте в VS Code розширення:
- **Python** (Microsoft)
- **Jupyter** (Microsoft)

Це можна зробити через вкладку Extensions (`⌘⇧X` на macOS / `Ctrl+Shift+X` на Windows) або при відкритті `.ipynb`-файлу VS Code сам запропонує встановити потрібні розширення.

## Запуск

1. Відкрийте `LLM_selection_comparision.ipynb` у VS Code.
2. Виберіть kernel — створене вами `.venv`.
3. Переконайтесь, що Ollama встановлена і запущена локально ([https://ollama.com/download](https://ollama.com/download)).
4. Виконуйте комірки послідовно згори вниз.
